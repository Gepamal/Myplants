# Myplants

Petite web app (PWA) pour suivre l'entretien de mes plantes : arrosage, engrais, taille, rempotage, sortie/rentrée, alertes gel.

- Fiches et règles : `data.js`
- Logique et interface : `app.js`
- Historique stocké dans le navigateur (localStorage), export/import JSON dans Réglages
- Météo : [Open-Meteo](https://open-meteo.com), sans clé

Installation sur Android : ouvrir l'URL https://gepamal.github.io/Myplants/ dans Chrome → menu ⋮ → "Ajouter à l'écran d'accueil".
